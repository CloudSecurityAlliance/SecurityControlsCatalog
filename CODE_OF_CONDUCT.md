# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of
conduct. We are committed to providing a welcoming, harassment-free experience
for everyone participating in this repository and the working group.

The full text is available at:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Enforcement

Report unacceptable behavior to **info@cloudsecurityalliance.org**. All reports
will be reviewed and investigated promptly and fairly.
